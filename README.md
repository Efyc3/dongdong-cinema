## 本地与其他主机

Node.js 22.13 以上：

```sh
npm ci
npm run build
npm start
```

生产构建生成 `.next/standalone/server.js`；构建后脚本自动补齐公开资源和静态文件。Docker 构建会重新安装对应系统的依赖，不要上传本机 `node_modules` 或 `.next`。

```sh
docker build -t dongdong-cinema .
docker run --rm -p 3000:3000 dongdong-cinema
```

## 提前缓存与本地观看

视频使用 Hls.js 时默认提前缓冲 3 分钟，可选择 30 秒、3 分钟或 10 分钟；播放器显示实际已缓冲时长。原生 HLS 和普通视频由浏览器管理缓冲。支持跨域下载的 MP4/WebM 直链可保存到本地，HLS 分流目前仅支持提前缓冲。资料库的“打开本地视频”可播放已保存的文件。

漫画在当前页加载后自动预读后面 3 页。“缓存本章”将图片保存到当前浏览器的 IndexedDB，支持进度、取消、续存和清理；已缓存章节从“资料库 → 本地缓存”打开。网站页面和脚本同时缓存，正常完成准备后可断网回读。来源限额和访问规则仍按原站执行。

漫画章节区的“批量缓存”支持逐章勾选、全选所有分页、缓存所选和删除所选缓存；资料库的“管理缓存”支持多选、全选和批量删除。缓存队列逐章逐页处理，完整章节和已保存图片自动跳过；取消后保留已缓存的部分。

## 站内来源适配

Anime1 使用其正常公开网页票据和来源签发的匿名播放会话，接入站内 MP4 播放。本站只保存短期、不超过一小时的内存会话；媒体地址与来源 Cookie 留在服务器，网页使用随机播放地址。固定 API 和媒体主机，不接收任意转发地址。来源限制和失效会话停止播放，不尝试绕过。

检查了 [copymanga-downloader](https://github.com/lanyeeee/copymanga-downloader)。该项目是 Tauri 桌面下载器，本站没有执行或复用其账号池、App 身份与限额规避代码。拷贝漫画适配独立读取正常公开网页的章节与图片载荷；固定元数据与已验证图片主机，拒绝来源明确限制的章节。原站返回空载荷时会提示前往原站，实际可用性以部署后的验证为准。

2026-10-04 普通请求检查中，4K 影院、次元城、MoMoVOD 和 VidHub 返回 403；AGE 播放页提示不提供电脑端播放；茶杯狐当前页面没有可解析的搜索和播放器。这些入口暂保留外部打开。现有樱之空和 girigiri 的公开播放器解析已扩展至完整 JSON 配置和原生视频标签，不执行外部脚本。
